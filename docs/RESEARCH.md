# Grok Imagine Image research note

## Positioning

Grok Imagine Image is xAI's image-generation and image-editing model. Useful prompts make composition, subject identity, lighting, typography, surface treatment, and edit boundaries explicit, while keeping the requested transformation easy to evaluate against the source image.

## Curation method

Community cases were discovered with the local twitterapi.io workflow on 2026-07-18, then screened for explicit model evidence, complete prompt text, source attribution, visible result media, uniqueness, and production value. Raw selected records are retained in `data/research/` for auditability.
